# 岩體材料參數換算報告

## 1. 目標參數

本次輸出供 FLAC3D Mohr-Coulomb 材料使用的五個參數：

- `density`：kg/m3
- `young`：GPa
- `poisson`：無因次
- `cohesion`：kPa
- `friction`：degree
- `tension`：kPa

## 2. 地質排序約束

依使用者指定，強度排序固定為：

```text
SS_NK > Interbedded_ST > SH_ST > SS_NC > Fault
```

本版將 Fault 拆成 `Fault_up / Fault_core / Fault_down` 分別計算，最後依分層厚度加權整合成單一 `Fault`。
試驗統計值若違反此排序，材料表採用排序約束後的設計值；原始統計仍另存於 `raw_group_statistics.csv` 供追查。

## 3. UCS 取得方式

UCS 是單軸抗壓強度。試體在無側向圍壓狀態下受軸向壓縮，破壞時最大荷重除以截面積：

```text
UCS = P_failure / A
```

本案 Excel 已提供 `單壓強度qu(MPa)`，因此不重做單位換算；只做孔號與深度對回模型地層。

## 4. GSI 初估

先用 RQD 的保守經驗式估算：

```text
GSI_raw = clip(RQD_median - 10, 10, 65)
```

若該地層沒有 RQD，使用保守地質初值；之後依強度排序做最小間距 2 的單調約束。
表中的 `GSI_from_RQD` 是 RQD 初估值，`GSI` 是最後採用值。
`SS_NC` 因屬南莊層且較年輕、較弱，雖然 RQD 初估較高，設計值仍採更保守上限。
本版計算時將 `SS_NC` 拆成遠離斷層的 `SS_NC` 與受逆斷層損傷的 `SS_NC_damage`，最後再合併回單一 `SS_NC`。
Fault 子帶中，`Fault_core` 採最低 GSI；`Fault_up/down` 視為 damage zone，允許比 core 稍高。
Fault 整合時不再只用原始厚度比例，而是提高 up/down damage zone 權重、降低 core 權重，以測試較強的等效 Fault 參數。

## 5. Hoek-Brown 參數

採用廣義 Hoek-Brown：

```text
σ1 = σ3 + σci * (mb * σ3 / σci + s)^a
mb = mi * exp((GSI - 100) / (28 - 14D))
s  = exp((GSI - 100) / (9 - 3D))
a  = 0.5 + (1/6) * (exp(-GSI/15) - exp(-20/3))
```

本次 `D = 0.5`，代表鑽炸與機械開挖造成的中等擾動。

## 6. HB 轉等效 Mohr-Coulomb

先估隧道問題的有效最大圍壓範圍：

```text
σ3max / σcm = 0.47 * (σcm / (γH))^(-0.94)
γH = density * g * H
```

其中 H 由鑽孔地表高程與隧道 crown 線形高程估算。接著在 `0 <= σ3 <= σ3max` 上建立 HB 曲線，並用最小平方法擬合：

```text
σ1 = A * σ3 + B
sin(phi) = (A - 1) / (A + 1)
c = B * (1 - sin(phi)) / (2 * cos(phi))
```

## 7. 岩體變形模數

採 Hoek-Diederichs 型式，由完整岩石靜彈性模數 Ei 折減為岩體模數 Erm：

```text
Erm = Ei * [0.02 + (1 - D/2) / (1 + exp((60 + 15D - GSI)/11))]
young = Erm / 1000
```

## 8. 張力強度

以 HB 岩體拉力強度與 MC 包絡線張力上限兩者取較小值：

```text
tension_HB = s * sigma_ci / mb
tension_MC_limit = c / tan(phi)
tension = min(tension_HB, tension_MC_limit)
```
